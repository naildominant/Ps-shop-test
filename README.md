# PS SHOP: витрина игр для PS4 и PS5

Сайт-магазин в стиле PlayStation Store. Каталог собран из Telegram-канала [@psshopgo](https://t.me/psshopgo).

## Что есть на сайте

- **Главная**: баннер-карусель (GTA VI и другие), полки «Предзаказы», «Хиты продаж», «Новое в магазине», «Играть вместе», «До 200 000 сум», «VR».
- **Каталог**: 294 игры с обложками и ценами в сумах. Есть фильтры (PS5, PS4, предзаказ, хиты, русская озвучка, для компании, VR), сортировка и поиск. Поиск понимает и русские названия: «гта», «фифа», «человек паук».
- **Страница игры**: выбор платформы или издания, цена, язык, число игроков, дата выхода, ссылка на пост в канале.
- **Корзина**: сохраняется в браузере. Покупатель оформляет заказ, указывая имя и телефон, и готовый текст заказа уходит менеджеру @Gaynullin_Nail в Telegram.
- **Чат**: помощник по ценам и частым вопросам (как купить, оплата, гарантия, подписки, аренда). Если ответа нет, он переводит покупателя на менеджера в Telegram.
- **Подписки и аренда**: PS Plus (Essential, Extra, Deluxe), EA Play, аренда PS5.

## Как открыть

Это обычный статический сайт, без сервера и сборки. Достаточно открыть `index.html` в браузере.

**Бесплатная публикация через GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → ветка с сайтом, папка `/ (root)` → Save. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `styles.css` | оформление |
| `app.js` | логика: каталог, корзина, чат, страницы |
| `games.js` | каталог игр (название, цены, язык, обложка) |
| `covers/` | обложки игр |
| `tools/` | скрипты, которые собирают `games.js` из канала |

## Как поменять цену или добавить игру

Откройте `games.js`, найдите игру и поменяйте `ps4` / `ps5` (цена в сумах). Чтобы добавить игру, скопируйте любой блок `{ ... }`, поменяйте поля и положите обложку в `covers/`.

Можно обновить весь каталог из канала разом. Для этого скачайте страницы `https://t.me/s/psshopgo` в папку `tg/` и запустите по очереди `tools/parse.py`, `tools/games.py`, `tools/build.py`.
