# Задачи по сайту (от 21.11.2026)

Делать по одной, после каждой ждать подтверждения владельца.

1. Кнопки статуса под заявкой в @psshop_zayavki_bot (PSSHOP BOT): ✅ Купил / ⏳ В обработке (лид) / ❌ Отказался. Статус пишется в Google Таблицу «PS SHOP CRM», лист «Заявки», колонка «Статус».
2. Подтверждение клиенту через тот же бот: после заказа на сайте кнопка → бот (start с номером заявки) → «Заявка №… принята», потом уведомления о смене статуса. Общение с клиентом остаётся в личке @Gaynullin_Nail. Открытый вопрос: оставить ли на сайте кнопку «Открыть чат с менеджером» рядом с кнопкой бота.
3. Проверка телефона на сайте: неполный узбекский номер (+998 и 9 цифр) не пропускать.
4. Ускорить первое открытие: перенос с GitHub Pages на Cloudflare (есть узел в Ташкенте), домен psshop.uz тот же; шрифты/обложки ниже экрана позже; кэш при повторном заходе. Платный хостинг не нужен.
5. Убрать ссылку «Отзывы клиентов» рядом с заголовком «Гарантии» (ru и uz).
