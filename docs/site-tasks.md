# Задачи по сайту (от 21.11.2026)

Делать по одной, после каждой ждать подтверждения владельца.

1. Кнопки статуса под заявкой в @psshop_zayavki_bot (PSSHOP BOT): ✅ Купил / ⏳ В обработке (лид) / ❌ Отказался. Статус пишется в Google Таблицу «PS SHOP CRM», лист «Заявки», колонка «Статус».
   Дополнение: 4-я кнопка «💸 Купил со скидкой» → бот спрашивает сумму, владелец пишет число → в таблицу. В «Заявках» новая колонка «Оплачено, uzs»: Купил = сумма заявки, Со скидкой = введённая сумма, остальные пусто. Отдельно считать выручку по обработанным заявкам (сегодня / 7 / 30 дней) в «Сводке» и в отчёте. Для старых заявок без кнопок — статус можно выбрать в таблице из списка.
2. Подтверждение клиенту через тот же бот: после заказа на сайте кнопка → бот (start с номером заявки) → «Заявка №… принята», потом уведомления о смене статуса. Общение с клиентом остаётся в личке @Gaynullin_Nail. Открытый вопрос: оставить ли на сайте кнопку «Открыть чат с менеджером» рядом с кнопкой бота.
3. Проверка телефона на сайте: неполный узбекский номер (+998 и 9 цифр) не пропускать.
4. Ускорить первое открытие: перенос с GitHub Pages на Cloudflare (есть узел в Ташкенте), домен psshop.uz тот же; шрифты/обложки ниже экрана позже; кэш при повторном заходе. Платный хостинг не нужен.
5. Убрать ссылку «Отзывы клиентов» рядом с заголовком «Гарантии» (ru и uz).
6. Город посетителя без «VPN-городов»: в таблице показывать настоящее место, а не страну VPN-сервера, с маленькой пометкой «(VPN)». Признаки VPN: часовой пояс телефона (Asia/Tashkent, Asia/Samarkand) не совпадает со страной по адресу, или адрес принадлежит дата-центру. Настоящий город: из прошлого визита того же посетителя без VPN, иначе «Узбекистан (VPN)». Явных ботов (1 страница, меньше 15 секунд, «компьютер, другое», дата-центр) помечать «бот» и не считать в сводке по городам.
7. Лист «Сводка», график «Визиты по дням»: даты слева направо по порядку (старые слева, сегодня справа), короткие подписи «18.11», дни без визитов показывать нулём. Заодно округлить «Средне страниц» и «Средне минут» до одного знака после запятой.
8. «Мой отчёт» сделать понятным и визуальным: крупные цифры-карточки (сегодня / 7 дней / заказы / сумма), полоски-графики (откуда пришли, какие игры смотрят), короткие строки последних посетителей со значками (📱/💻, город, что смотрел, итог ✅ заказ / 🛒 бросил корзину / — ушёл). Поиск записывать только итоговым словом, а не каждой буквой («A pal, A way…» — мусор). Решение владельца: «Посетители» = служебный лист для Claude (сырые данные, коды, всё подробно: часовой пояс, VPN, провайдер и т.д.), его можно расширять как угодно; из него собираются понятные листы/страница для владельца. Служебный лист — в конец, подписать «служебный». Открытый вопрос: делать в самой таблице или отдельной страницей-отчётом для телефона.
