Сайт PS SHOP (psshop.uz) уже готов и работает. Ничего не переделывай с нуля и не меняй дизайн. Задача — проверить сайт и доработать только то, что реально мешает: тормозит, дёргается, ломается или долго грузится. Главное — телефон.

## 0. Перед началом
- Прочитай `CLAUDE.md`, `docs/TZ.md`, `README.md`.
- Код: `scripts/build.py` (собирает сайт в `dist/`), `src/static/app.js`, `src/static/styles.css`, `src/static/fonts/`, `worker/worker.js`.
- Собери сайт: `pip install pillow && python3 scripts/build.py`, запусти `python3 -m http.server 8000 --directory dist`. `catalog.py` не запускай (он ходит в канал), работай с данными, что уже лежат в `data/`.
- Проверяй через скилл `webapp-testing` (Playwright). Узбекскую версию (корень) и русскую (`/ru/`).

## 1. Сначала замерь, потом чини
Снимай замеры **до** правок и **после**, на телефоне (iPhone ~390px, медленный 4G: ~1.6 Мбит/с, задержка 150 мс, процессор ×4 медленнее) и на компьютере (1440px). Страницы: главная, каталог, страница игры, корзина, чат.
- Сколько весит страница всего и по типам (HTML, CSS, JS, шрифты, картинки), сколько запросов.
- LCP (когда видна главная картинка/заголовок) — цель < 2.5 с на телефоне.
- CLS (прыжки вёрстки) — цель < 0.05.
- Долгие задачи JS > 50 мс, INP (отклик на нажатие) — цель < 200 мс.
- Плавность прокрутки каталога: нет ли рывков (замерь кадры в секунду при прокрутке).
- Ошибки в консоли и битые ссылки/картинки (404).
Результаты запиши таблицей в `docs/speed-report.md`.

## 2. Что проверить и при необходимости поправить
**Загрузка**
- Обложки: webp, правильный размер под карточку (не больше 2× от показанного), `loading="lazy"` и `decoding="async"` у всего ниже первого экрана, у первых 1–2 на экране — без lazy и с `fetchpriority="high"`. У всех `<img>` есть `width`/`height` (чтобы не прыгало).
- Шрифты: только нужные начертания, `font-display: swap`, preload только того, что видно сразу. Не вернуть мигание текста (см. коммит 4060ba2 — content-visibility убрали намеренно).
- CSS (~41 КБ) и JS (~33 КБ): убрать неиспользуемое, если его много; JS с `defer`; критичное для первого экрана не блокировать.
- Кэш: у файлов в `static/` в адресе есть версия (`?v=` или хэш), чтобы после обновления каталога у людей не оставалась старая версия.
- Большой список игр: если каталог рисуется весь сразу и это тормозит телефон — подгружать порциями при прокрутке.

**Плавность**
- Анимации только через `transform` и `opacity`, без анимации `width/height/top/left/box-shadow`.
- Обработчики прокрутки и касаний — `{ passive: true }`, поиск с задержкой (debounce ~150 мс).
- Нет `backdrop-filter`/тяжёлых теней на длинных списках, если они дают рывки на телефоне.
- Учитывать `prefers-reduced-motion`.
- Открытие/закрытие корзины и чата без рывков и прыжков страницы, фон не прокручивается под окном.

**Работоспособность (пройди руками в Playwright)**
- Поиск: находит игру по-русски, по-узбекски, по-английски и с опечаткой (есть `scripts/search_aliases.py`).
- Фильтры каталога PS4/PS5, сортировка.
- Корзина: добавить, изменить количество, удалить, обновить страницу — корзина сохранилась (localStorage). Отправка заказа уходит в worker → Telegram. **Реальную заявку не отправляй** — подмени запрос к `psshop.psshop.workers.dev` в Playwright и проверь, что текст заказа правильный (названия, платформы, цены в формате `229 000 сум`, итог).
- Чат-помощник отвечает на частые вопросы и даёт кнопку перехода к менеджеру https://t.me/Gaynullin_Nail.
- Переключение языка uz ⇄ ru ведёт на ту же страницу на другом языке.
- Страница игры: обложка, цены, кнопка «в корзину», превью ссылки (og-теги) для Telegram.
- Работает без интернета для картинок: если обложка не загрузилась — аккуратная заглушка, а не пустой квадрат.
- Нет горизонтальной прокрутки на 360–390px, кнопки не меньше 44px по высоте, текст не обрезается.
