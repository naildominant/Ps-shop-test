#### Решения и правила
- Шаблон поста игры: 🎮 НАЗВАНИЕ 🎮 / ↪️язык / ↪️Издание / ↪️Кол-во игроков / пустая строка / цитата 💵ЦЕНА PS4/PS5 - N UZS / пустая строка / жми👉ГЕЙМПЛЕЙ + тематический обычный эмоджи (<plain>), ОТЗЫВЫ🔥 (t.me/xpsshopotziv), АКСЕССУАРЫ (t.me/PsShopConsolesDualsense), 🛒НАПИСАТЬ НАМ (t.me/Gaynullin_Nail).
- Премиум-коды шаблона: 🎮5467583879948803288 ↪️5314606606678237326 💵5409048419211682843 👉5465198403573012261 🔥5807654210715522568 🛒5440841102871517055 🇷🇺5190924072678085128. 5429240168571776335 = логотип Rockstar (не 🤩).
- Премиум-эмоджи — только проверенные по картинке (designer/emoji.json; чёрный список ps-shop-autopost/data/emoji_verified.json). Нет подходящего — подходящий обычный; владелец присылает боту «обычный -> премиум».
- На задачу — всегда НОВЫЙ пост из присланного (кроме правок). Видео (геймплей, иначе трейлер) обязательно. Язык — только подтверждённый. Обложки игр — квадрат 1:1. Новости — своя картинка с логотипом PS SHOP слева сверху. Истории — без искажения картинки и логотипа.
- В канал без кнопки владельца не публиковать (исключение — автоповышение цен, разрешено владельцем 21.11). Где сомневаешься — спросить. Перед массовыми правками — пример. Секреты не в чат и не в публичный репо.
