# Состояние рабочих чатов

Здесь хранится «память» между чатами Claude. Каждый файл — одна цепочка чатов:

- `sayt.md` — чаты «САЙТ PS SHOP #N» (сайт, каталог, CRM).
- `bot.md` — чаты «БОТ ПОСТИК #N» (посты для канала, бот).

Каждый день в 5:31 по Ташкенту служебная задача создаёт новый чат и передаёт ему,
что произошло за сутки; новый чат первым делом дописывает это сюда и сохраняет в main.
Посетители сайта эти файлы не видят.

Формат файла: разделы «Цель», «Сделано и решения», «Факты и ссылки»,
«Предпочтения владельца», «На чём остановились / очередь», «Открытые вопросы».
Держать файл коротким (до ~120 строк): устаревшее удалять, а не копить.
