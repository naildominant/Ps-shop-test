# Память рабочих чатов

Цель — чтобы каждый новый чат Claude знал весь контекст прошлых. Посетители сайта эти файлы не видят.

- `sayt.md` — база знаний чатов «САЙТ PS SHOP #N» (сайт, каталог, CRM); `sayt-log.md` — журнал по дням.
- `bot.md` — база знаний чатов «БОТ ПОСТИК #N» (посты, бот); `bot-log.md` — журнал по дням.

База знаний — полная, не «на чём остановились»: как всё устроено, все решения и правила,
предпочтения владельца, что сделано, планы, проблемы. Ничего не удалять без замены,
устаревшее — в раздел «Архив» в конце. Журнал только пополняется (новое сверху).

Каждый день в 5:31 по Ташкенту служебная задача создаёт новый чат с конспектом прошлого,
и новый чат вливает его сюда и сохраняет в main.
