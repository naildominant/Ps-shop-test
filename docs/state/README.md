# Память рабочих чатов

Цель — чтобы каждый новый чат Claude знал весь контекст прошлых. Посетители сайта эти файлы не видят.

- `sayt.md` — база знаний чатов «Сайтер #N» (сайт, каталог, CRM); `sayt-log.md` — журнал по дням.
- `bot.md` — база знаний чатов «Постик #N» (посты, бот); `bot-log.md` — журнал по дням.
- `claude.md` — база знаний чатов «Мастер #N» (правила, перенос чатов, память, скиллы); `claude-log.md` — журнал.
- `bos.md` — база знаний чатов «Бос #N» (руководитель команды, надзор за чатами).
- `design.md` — база знаний чатов «Дизайнер #N» (картинки, баннеры, графика для сайта).
- `reklama.md` — база знаний чатов «Маркетолог #N» (объявления OLX, BIR BIR).

До 22.11 чаты назывались «САЙТ PS SHOP», «БОТ ПОСТИК», «НАСТРОЙКА CLAUDE», «БОС».

База знаний — полная, не «на чём остановились»: как всё устроено, все решения и правила,
предпочтения владельца, что сделано, планы, проблемы. Ничего не удалять без замены,
устаревшее — в раздел «Архив» в конце. Журнал только пополняется (новое сверху).

Перенос в новый чат: каждый чат сам переносится при первом сообщении владельца за день
(правило в CLAUDE.md). Утренние задачи по расписанию для этого не годятся и выключены.
