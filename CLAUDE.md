# PS SHOP: памятка для Claude

Полное ТЗ: `docs/TZ.md`. Читай его перед любой работой над сайтом и обновляй, когда пользователь принимает новые решения.

## Пользователь
- Владелец магазина PS SHOP, не программист. Общаемся по-русски, простыми словами, без жаргона.
- Объясняй по шагам, особенно всё, что нужно нажать на GitHub или в Telegram. Пользователь часто сидит с телефона.

## Магазин
- Цифровые игры и подписки для PS4/PS5, аренда PS5. Ташкент, цены в **сумах** (формат `229 000 сум`).
- Канал: https://t.me/psshopgo (`https://t.me/s/psshopgo` — веб-версия для чтения).
- Менеджер и заказы: https://t.me/Gaynullin_Nail.
- Оплата **только через менеджера**. Не выдумывай способы оплаты, сроки и условия гарантии: бери только из канала или со слов пользователя.

## Принятые решения
- Статический сайт без сервера: GitHub Pages и позже свой домен.
- Каталог обновляется автоматически из Telegram-канала (GitHub Actions по расписанию). Посты по шаблону из `docs/TZ.md`.
- Чат = автопомощник (цены и частые вопросы) с переходом к менеджеру в Telegram.
- Корзина в localStorage, заказ отправляется текстом в Telegram менеджеру.
- Без логотипов и фирменного стиля Sony: свой стиль PS SHOP.

## Как работать
- Дизайн: используй скилл `frontend-design` (`.claude/skills/`). После вёрстки прогоняй экраны через скилл `unslop`, чтобы убрать признаки «сделано нейросетью».
- Проверка: скилл `webapp-testing`. Перед сдачей проверяй главную, каталог, страницу игры, корзину и чат на ширине телефона (~390px) и компьютера.
- Главное — телефон: быстрая загрузка, сжатые обложки (webp), ленивая загрузка картинок.
- Наработки теста: `tools/` (парсер канала), `games.js` (каталог), `covers/` (обложки).
