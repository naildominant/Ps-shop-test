# PS SHOP — дизайнер объявлений

Это рабочая папка постов и картинок для Telegram-канала PS SHOP (t.me/psshopgo).
Владелец: Наиль (Ташкент). Общаемся по-русски, прямо и по делу. Короткие ответы на простые вопросы, подробные на сложные. Если нужно несколько ответов — спрашивай по одному вопросу за раз.
Инструкции давай по 1–2 действия за сообщение, жди ответа и только потом следующий шаг.
Вопросы задавай обычным текстом, по одному. **Не используй кнопки-варианты (AskUserQuestion)**: владельцу неудобно, он отвечает сам. Можно коротко подсказать примеры ответа в тексте.

## Главное
- Перед каждой картинкой — навык **psshop-art-director** (`.claude/skills/psshop-art-director/SKILL.md`): вопросы тестом, журнал `journal.md`, ротация композиций, проверка.
- Для любого поста используй навык **psshop-telegram-posts** (`.claude/skills/psshop-telegram-posts/SKILL.md`).
- К каждому посту обязательно делай картинку. Перед картинкой — 3 ключевых вопроса по одному.
- Креатив обязателен: однотипных картинок быть не должно.
- Стиль владельца: **3D-объекты + плоский 2D-текст**. Предметы объёмные (толщина, перспектива, тени, отражения), текст плоский, чёткий, без 3D-эффектов.
- **Шрифты:** FreeSerif Italic владельцу не нравится, не использовать. Для подзаголовка-пары владелец выбрал Unbounded (Medium, строчные).
- **Подписки PS Plus:** на картинке должно быть сразу видно, что это про подписку: свой объёмный золотой «плюс» + надпись «PS PLUS» (не копировать логотип Sony/PlayStation/PS Plus). Пример: `scripts/post_blackfriday_psplus.py`.
- **Логотип не трогать:** только слева сверху, как есть. Не делать из куба логотипа 3D-декор и героя.
- Для темы «сайт» 3D-героем делать объёмный телефон с открытым psshop.uz (`scripts/post_site_phone3d.py`).
- **Два вида постов (решение владельца 17.11):** новость → своя картинка-дизайн с логотипом PS SHOP; объявление игры → **только обложка игры** (без дизайна и логотипа) + текст с ценой.
- Цель владельца: полная автоматика (бот сам находит игры, считает цены, готовит пост), владелец только подтверждает в боте. Источник наличия — Авито поставщика (hps_store), автоматическое чтение Авито заблокировано/запрещено — ищем замену (таблица поставщика).
- Владельцу отправлять **только итоговую картинку**. Черновики проверять в уменьшенном виде и не показывать.

## Структура папки
- `assets/logo.png` — логотип PS SHOP (куб с P и S + надпись, тёмный фон).
- `assets/covers/` — обложки и арты игр (`название-игры.jpg`). **Картинки игр сначала всегда искать в канале владельца** (`https://t.me/s/psshopgo?q=<игра>`); если там нет — написать владельцу и искать вместе. Пост про игру — всегда с обложкой игры.
- `assets/fonts/` — шрифты с кириллицей (лицензия OFL, образцы в `specimen.png`): Unbounded, Russo One, Oswald, Montserrat, Rubik Mono One (огромные слова); Playfair Display Italic, Cormorant Italic (fashion-курсив); Manrope (мелкий текст); Press Start 2P, Rubik Glitch (ретро и глитч). Плюс системные Inter / Inter Display.
- `assets/shots/` — скриншоты psshop.uz (телефон `m_*.png`, компьютер `d_*.png`). Переснимать Playwright'ом, если сайт поменялся.
- `scripts/psfx.py` — **общая библиотека приёмов, начинать любую картинку с неё**: `import sys; sys.path.insert(0,"scripts"); from psfx import *`.
  Шрифты `font("unbounded",200)`; фон `neon_bg()`, `diagonal_split`, `retro_grid`, `sparks`, `grain`; текст `text_img` (сжатие, разрядка), `spaced`, `lined`, `highlight`, `cta_pill`, `chroma_shift`; шапка `header()` (логотип слева сверху без изменений); 3D: `Cam`, `phone3d`, `card3d`, `box3d`, `reflection`, `shadow`, `glow`, `pocket`; проверка `check({...})` и `preview()` для самопроверки.
- `scripts/` — рабочие скрипты прошлых удачных картинок (Python, Pillow + numpy). Брать как основу техник, но композицию каждый раз делать новую:
  - `story_site_phone.py` — сторис «у нас открылся сайт»: мокап телефона, огромное слово, стеклянные плашки, ретро-сетка.
  - `post_timer_fashion.py` — пост «живой таймер до релиза»: арт игры карточкой, куб на фоне, fashion-типографика (курсив + огромное слово + тонкая строка с разрядкой). Владельцу понравился больше всего.
  - `post_mosaic_3d.py` — 3D-мозаика неоновых плиток с отсчётом, центральная плитка с логотипом игры.
  - `post_countdown_boxes.py` — логотип игры + стеклянные плашки отсчёта.
  - `post_site_fan.py` — пост «у нас открылся САЙТ»: настоящие скриншоты psshop.uz стеклянными 3D-пластинами веером выходят из огромного слова.
  - `post_site_phone3d.py` — тот же пост с настоящим 3D-телефоном (толщина корпуса, перспектива, кнопки), выходящим из слова САЙТ. Итоговый вариант.
  - `post_logo_hero_bigword.py` — 3D-куб логотипа как герой перед огромным словом.
- `examples/` — готовые удачные картинки для ориентира.
- `output/` — сюда сохранять новые картинки.

## Публикация в канал (бот)
Схема: владелец пишет задачу Claude в этом чате → Claude делает пост → **Claude сам отправляет превью** владельцу в Telegram (пост без кнопок + сообщение-подсказка с кнопками) → **владелец пересылает пост в канал со «Скрыть имя отправителя»** (так сохраняются премиум-эмодзи: если пост выкладывает бот, Telegram в канале заменяет премиум-эмодзи обычными — проверено 17.11) → воркер видит `channel_post` и ставит статус `published`. Кнопки под подсказкой: «❌ Нужны правки» (бот спрашивает, что поменять) и запасная «🤖 Выложить ботом» (эмодзи станут обычными). На GitHub владелец не заходит.
- Пост = папка `posts/<ГГГГ-ММ-ДД-тема>/` с `image.png` и `post.html` (HTML Telegram). Проверка: `python3 scripts/publish.py posts/<папка> --check`.
- Залить пост в `main` (PR + merge, владелец разрешил), затем отправить превью: GitHub MCP `actions_run_trigger` → `run_workflow`, `workflow_id: publish-post.yml`, `ref: main`, inputs `{"post": "<папка>", "action": "превью мне в личку"}`. Превью приходит с кнопками «✅ Опубликовать в канал / ❌ Отмена».
- **В канал Claude сам не публикует** — только владелец кнопкой ✅ (режим «опубликовать в канал» в workflow — запасной, только по просьбе владельца).
- Кнопки обрабатывает Cloudflare Worker `psshop` (`worker/worker.js`, раздел 4, адрес https://psshop.psshop.workers.dev): `/tgpost` — webhook (заголовок-секрет), копирует превью в канал, ставит «✅ Опубликовано — открыть». Токен бота хранится в KV `tgpost:token` (передан через режим workflow «подключить кнопки», сервер проверяет его через getMe). Секреты воркера: `TGPOST_SECRET`, `TGPOST_OWNER`=5562428297. Деплой воркера — Cloudflare API (`PUT .../workers/scripts/psshop` с `keep_bindings`), перед деплоем сверять с живой версией (`.../content/v2`).
- Бот: @psshop_postTG_bot (админ канала с правом публикации). Секреты GitHub: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_CHAT_ID`. Репозиторий **публичный**: никаких секретов в коде, логах и inputs workflow.
- Из облачной сессии api.telegram.org закрыт; воркер (workers.dev) и Cloudflare API доступны.
- **После каждого превью** ставить себе `send_later` (~10 мин): проверить `GET https://psshop.psshop.workers.dev/tgpost/status?post=<папка>&key=<TGPOST_SECRET>`. `published` → сообщить владельцу ссылку и записать в журнал; `cancelled` → **самому спросить здесь «что поменять?»**, показав `feedback` (ответ владельца боту после отмены), и делать правки; `pending` → ещё одно напоминание позже (не чаще 2–3 раз). После «Отмены» бот сам спрашивает в Telegram «Что поменять?».
- **Премиум-эмодзи:** у владельца Telegram Premium. Коды в `designer/emoji.json` (обычный эмодзи → custom_emoji_id), подставляются при отправке сами; если Telegram не примет — уйдут обычные. Любимые эмодзи владельца — `emoji_owner.json` (26 шт.), **предпочтительны в постах**; остальные собраны с t.me/s/psshopgo. В `post.html` пиши обычные эмодзи.
- Новые эмодзи: владелец присылает боту сообщение с премиум-эмодзи → бот отвечает «Запомнил…» → Claude забирает их `GET https://psshop.psshop.workers.dev/tgpost/emoji?key=<TGPOST_SECRET>` и дописывает в `emoji.json`/`emoji_owner.json`. Значение секрета Claude не хранит между сессиями: задать новый `TGPOST_SECRET` через Cloudflare API (`PUT .../secrets`), затем `GET /tgpost/setup?key=<новый>` (перерегистрирует webhook с новым секретом), потом читать `/tgpost/emoji`.
