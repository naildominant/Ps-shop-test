## Задачи (очередь)

### Утренний обход бота (решено владельцем 2026-11-21, делать по одному этапу)
Каждый день в **5:00 по Ташкенту** бот присылает владельцу в «БОТ ПОСТИК»:
- **Этап 1. Цены** (окончательно 21.11): обход в **6:00** Ташкент (`morning.yml`, cron 01:03 UTC): подорожало у поставщика → сразу правит цену в посте канала без подтверждения; подешевело → не трогает; рост больше чем вдвое → не меняет, пишет «проверьте». Отчёт кладётся на сервер бота и уходит **ровно в 7:00** (cron воркера `0 2 * * *`, KV `tgpost:report`). Вид: «1. НАЗВАНИЕ / PS5: 369 000 → 379 000», пустая строка между играми. Под отчётом кнопки «✅ Принято» (`prok`) и «✏️ Есть правки» (`prfix`) → агент (папка `prices`) пишет `out/price_set.txt` → цена в канале правится (`price_watch.py --set`).
- **Этап 2. Исправление постов: 1 пост в день.** Только посты об играх (новости, акции, аренду пропускать). Порядок: от самых свежих к самым старым. Проверить: чёткая квадратная обложка; премиум-эмоджи по теме игры (вместо обычного 🇬🇧 тоже премиум); ссылка на геймплей; ссылки ОТЗЫВЫ и АКСЕССУАРЫ (и весь шаблон). Формат тот же: БЫЛО + пост → СТАЛО + пост → «✅ Да / ❌ Нет».
- Три кнопки (уточнено владельцем 2026-11-21): **«✅ Да»** → вариант «СТАЛО» как есть ставится в тот же пост канала (не новый пост). **«❌ Нет»** → пост не трогаем вообще, оставляем как был. **«✏️ Правки»** → бот спрашивает «Что поменять?», владелец пишет правку, бот присылает новый вариант БЫЛО/СТАЛО с теми же тремя кнопками. Без «Да» в канале ничего не менять.
- **Следующая задача (поставил владелец 21.11): «Игра по названию».** Владелец пишет боту название игры (или несколько) → бот сразу присылает готовый пост этой игры из канала (пересылкой, с картинкой и премиум-эмоджи), чтобы владелец переслал клиенту. Цель — быстро отвечать клиентам. Решено: (1) отдельная кнопка в меню «🔎 Найти игру» → владелец пишет названия → бот присылает посты. (2) Игры нет в канале → бот проверяет у поставщика: нет → «данной игры нет в наличии»; есть → сам готовит объявление по шаблону и присылает вместе с остальными. (3) Новое объявление приходит как обычное превью с обычными кнопками (Опубликовать / Отправить позже / Нужна доработка / Отменить).
