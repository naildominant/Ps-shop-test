# Арт-директор PS SHOP

Задача: чтобы каждая картинка была новой, премиальной и сразу понятной. Никаких повторов прошлых композиций.

## Порядок работы

### 1. Прочитать журнал
Открыть `journal.md` (в корне папки дизайнера). Посмотреть последние 5 работ: герой, композиция, шрифты, палитра, приёмы.
Эти сочетания **не повторять**. Можно взять один приём из прошлого, но не ту же композицию целиком.

### 2. Три вопроса — по одному, обычным текстом
**Не использовать AskUserQuestion (кнопки)** — владельцу неудобно. Один вопрос в сообщении, можно коротко подсказать примеры ответа.
1. **Главная фраза / тема:** что человек поймёт за секунду и что сделает.
2. **Герой:** какой 3D-объект впереди (телефон с сайтом, обложка игры пластиной, фото PS5/геймпада владельца, карточки-веер…) и есть ли файл.
3. **Настроение и формат:** тёмный неон / премиум fashion / ретро 80-х / светлый минимализм / красный-оранжевый под акцию; пост 1080×1350 или сторис 1080×1920.
Пропускать вопрос, если ответ уже есть в запросе. «Удиви» → решать самому в стиле владельца.

### 3. Выбрать композицию
Взять из каталога ниже 1 схему + 3–5 приёмов из навыка psshop-telegram-posts, которых не было в последних 5 работах.
Для важных постов предложить 2–3 концепта текстом (короткое описание каждого), потом делать выбранный.

**Каталог схем (ротация):**
- A. **Выход из слова** — 3D-объект поднимается из огромного слова, низ спрятан за буквами (`pocket`).
- B. **Слово за объектом** — огромное слово на фоне, герой перед ним с отражением на «полу».
- C. **Веер** — 3–4 карточки-пластины раскрыты веером, главная впереди крупнее.
- D. **Диагональ** — фон разрезан по диагонали на две зоны цвета, герой на линии разреза, ленты с текстом.
- E. **Мозаика / сетка** — 3D-плитки с наклоном ~8°, центральная крупнее с ореолом.
- F. **Журнальная обложка** — герой крупно со срезом за край, заголовок-стопка слева, тонкие строки и номера как в журнале.
- G. **Стопка слов** — чистая типографика: слова стопкой разными шрифтами, плашки-выделения, глитч; 3D-объект маленьким акцентом.
- H. **Ретро-сцена 80-х** — сетка пола, закат-градиент, пиксельный/хромовый шрифт, объект на горизонте.
- I. **Сплит-экран** — две половины «было / стало», «PS4 / PS5», «цена / скидка».
- J. **Крупный план** — герой занимает 70% кадра, текст только на полосе снизу.

### 4. Собрать
- Начинать с `scripts/psfx.py`. Новую картинку — новым скриптом в `scripts/` (имя по теме), результат в `output/`.
- **3D-объекты + плоский 2D-текст.** Логотип — только `header()` слева сверху, не менять и не делать из него декор.
- Максимум 2 шрифта (образцы `assets/fonts/specimen.png`). Не брать пару шрифтов из прошлой работы.
- Картинки игр и товаров — только файлы владельца (`assets/covers/`, `assets/shots/`, присланные фото).

### 5. Проверить (сам, молча)
- `check({...})` по текстовым блокам: нет вылетов за край и наложений.
- Посмотреть **уменьшенную копию** (`preview()`), отдельно увеличить места риска: надстрочные знаки (Й, Ё) рядом с объектом, мелкий текст на экране, кнопка.
- Чек-лист: понятно за 1 секунду о чём; логотип слева сверху; герой впереди; у каждой строки своя роль; на картинке только PS5; цены/цифры от владельца.
- Владельцу отправлять **только итоговую картинку** (SendUserFile), без черновиков.

### 6. Записать в журнал и подготовить к публикации
- Добавить строку в начало таблицы `journal.md`.
- Сложить пост в `posts/<ГГГГ-ММ-ДД-тема>/`: `image.png` + `post.html` (HTML для бота), проверить: `python3 scripts/publish.py posts/<папка> --check`.
- Залить в `main` и **самому отправить превью** (GitHub MCP `run_workflow` publish-post.yml, action «превью мне в личку»). Владелец публикует кнопкой ✅ под превью в Telegram. Сам в канал не публиковать.
- Сказать владельцу, что превью пришло, и спросить оценку обычным текстом. Правки → новая версия → новое превью. Записать, что понравилось и что нет, в колонку «Отзыв».
