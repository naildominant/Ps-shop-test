# Картинки (обязательно к каждому посту)

PNG 1080×1350 (пост) или 1080×1920 (сторис). Собираются в Python (Pillow + numpy). Готовые скрипты-примеры лежат в `scripts/`, логотип в `assets/logo.png`, шрифты в `assets/fonts/`.

## Перед каждой картинкой: 3 ключевых вопроса (по одному за раз, с вариантами ответа)
1. **Главная фраза:** что человек должен увидеть за секунду и что после этого сделать?
2. **Герой:** какой предмет ставим вперёд (игра, консоль, геймпад, чистая типографика) и есть ли для него файл?
3. **Настроение и формат:** тёмный неон / светлый минимализм / ретро 80-х / праздничный / премиум fashion; пост или сторис?
Если ответ уже есть в запросе — вопрос пропускай. Если владелец просит «удиви» — решай сам в его стиле (тёмный неон, премиум, fashion).

## Правила владельца
- **Креатив обязателен, однотипных картинок быть не должно.** Каждый раз новая композиция; для важных постов 2–3 концепта на выбор.
- **Логотип PS SHOP — слева сверху**, хорошо видно. Дополнительно можно большой полупрозрачный 3D-куб на фоне.
- **Впереди самый цепляющий предмет по теме** (горячая игра, PS5 для аренды, геймпад для аксессуаров). Картинка должна сразу и чётко объяснять, о чём объявление — без вычурности и перегруза.
- **Текст яркий, крупный, но приятный:** у каждой строки своя роль (акцент-курсив / главное слово / подзаголовок / тонкая строка с разрядкой).
- Платформа в текстах на картинках — **только PS5**.
- Изображения игр/товаров — только из файлов владельца (скрин PS Store, его фото, папка `assets/covers/`). Не скачивать обложки из интернета, не рисовать чужих персонажей и логотипы, не переделывать чужие дизайны (например, убирая с них бренд). Из референсов берём только приёмы.

## Приёмы (комбинировать 3–5 на картинку)
1. **Гигантское слово на фоне**, герой стоит перед ним и частично перекрывает — глубина.
2. **Герой по центру** с неоновым ореолом, тенью, иногда отражением и светящейся линией «пола».
3. **Диагональный разрез фона**, две зоны цвета.
4. **Ленты** с текстом («НОВИНКА», «ПРЕДЗАКАЗ», «−50%») вокруг объекта.
5. **Мелкая типографика:** КАПС с широкой разрядкой, верхняя «журнальная» строка, вертикальный текст по краю, тонкие линии.
6. **Декор:** сетка точек, «+», контурные круги, искры, лёгкое зерно, ретро-сетка пола (80-е).
7. **Заголовок-пара:** белая строка + строка с градиентом (розовый → голубой) и свечением.
8. **CTA-пилюля** со стрелкой (белая с тёмным текстом или с обводкой).
9. **Палитра:** база — тёмный фиолетово-синий неон; для разнообразия светлый минимализм, красный/оранжевый под акции.
10. **3D-плитки / мозаика:** плитки с выдавливанием, наклон ~8°, центральная плитка крупнее и с ореолом (пример: отсчёт до релиза).
11. **Мокап телефона** с интерфейсом сайта, курсор с волнами клика, парящие стеклянные плашки с преимуществами (пример: «у нас открылся сайт»).

## Типографика (половина успеха)
- **Слово-постер:** одно ключевое слово огромным сжатым шрифтом (сжатие ширины до ~70–80%), иногда наклон.
- **Fashion-пара:** элегантный курсив с засечками («живой», «у нас открылся») поверх/над огромным жирным словом («ТАЙМЕР», «САЙТ»). Следить, чтобы надстрочные знаки (Й, Ё) не врезались в соседнюю строку.
- **Тонкая строка с разрядкой** и линиями по бокам для спокойного подзаголовка («У НАС НА САЙТЕ», «ЗАХОДИ ПЕРВЫМ»).
- **Плашки-выделения:** фраза в цветном прямоугольнике, ключевое слово жирное.
- **Разбитое слово** стопкой, глитч/рваные края, кистевой ретро-шрифт для 80-х.
- Максимум 2 шрифта на картинку. Нужна кириллица. Шрифты — в `assets/fonts/` (Unbounded, Russo One, Oswald, Montserrat, Rubik Mono One, Playfair/Cormorant Italic, Manrope, Press Start 2P, Rubik Glitch) и системный Inter Display. FreeSerif Italic владельцу не нравится — не использовать. Образцы: `assets/fonts/specimen.png`.
